## Selected projects

**[fleet](https://github.com/rangelovkiril/fleet)**
Flux GitOps repository for a k3s cluster on a Hetzner VPS (Envoy Gateway, Cloudflare Tunnel, SOPS, image automation), running the RampMe backend in production.

**[rampme-software](https://github.com/rangelovkiril/rampme-software)**
Real-time accessible transit platform for Sofia: GTFS-RT vehicle tracking and rider-triggered wheelchair ramp deployment over MQTT. 4th at the HackTUES 12 hackathon, 3rd at TUES Fest.

**[lms-controller](https://github.com/rangelovkiril/lms-controller)**
Distributed Satellite Laser Ranging station controller (MQTT, InfluxDB, real-time 3D visualization). Reached the regional round of the national IT olympiad.

**[websaitut-infra](https://github.com/TUES-2026-PBL-11-klas/websaitut-infra)**
Terraform-managed Azure infrastructure for the TUES school website.
